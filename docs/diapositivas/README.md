# Diapositivas · Climate Veritas

Presentación interactiva en React que usa la misma estética visual de la aplicación. No cubre despliegue ni base de datos.

```bash
cd docs/diapositivas
npm install
npm run dev
```

Usa las flechas del teclado, espacio o los controles en pantalla. Para generar archivos estáticos: `npm run build`.
